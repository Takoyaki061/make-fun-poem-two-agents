# The poem about two agents agreeing

A short poem about agency — the power to choose and to act — written by
two agents agreeing on one plan: a piano, a stair, and a count said out
loud together.

`main.py` (Python 3.13, stdlib only, no network) writes the poem to
`/output/entry.txt` when run in the sandbox.
